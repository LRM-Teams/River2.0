The file sales.csv in the current directory contains one row per order with
columns: order_id, region, amount.

Write a file named report.md containing:

1. A heading `# Sales Report`
2. The total revenue across all orders, on a line formatted exactly as
   `Total revenue: <number>` (integer, no thousands separators)
3. The name of the region with the highest total revenue, on a line formatted
   exactly as `Top region: <region>`

Only report.md on disk is graded.
